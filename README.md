# Просебя · yandex.prosebya.ru · верстка · версия 2

Чистая статическая верстка (HTML + CSS, без сборки) первых двух секций страницы
[yandex.prosebya.ru](https://yandex.prosebya.ru/) (Tilda) плюс синий баннер «Остаёмся на связи».

**Что отличает версию 2 от первой** ([prosebya-yandex-landing](https://github.com/leratk22/prosebya-yandex-landing)):
на десктопе шапка и синяя плашка по ширине вёрстки (вровень с заголовком и плитками), плашка опущена между шапкой и hero, кнопки в ней нет,
«временный сервис» оформлен ссылкой. Мобильная версия как в первой.

В верстку вошло:

1. Шапка: логотип и кнопка «Скачать приложение» (на мобильной кнопка появляется в закреплённой панели).
2. Баннер «Остаёмся на связи» между шапкой и контентом: на десктопе плашка по ширине вёрстки, «временный сервис» — ссылка на `sessions.prosebya.ru`; на мобильной полоса на всю ширину с круглой кнопкой-стрелкой справа.
3. Hero «Всё для устойчивости и внутреннего равновесия»: на десктопе 4 карточки сеткой 2×2, на мобильной стопка карточек-аккордеон (открыта одна).
4. Секция «Инструменты самопомощи»: заголовок, табы (Забота о теле / Взаимодействие с другими / Управление эмоциями) и карусель карточек по каждой теме.

## Запуск

```bash
python3 -m http.server 4319
```

Открыть: http://localhost:4319/

## Структура

| Путь | Что внутри |
|---|---|
| `index.html` | Разметка страницы и небольшой скрипт (табы, карусель, аккордеон, закреплённая шапка) |
| `css/styles.css` | Токены (имена как в Paper), стили, мобильная версия |
| `fonts/` | Euclid Circular A: Regular, Medium, SemiBold |
| `assets/logo.svg` | Логотип Просебя |

## Поведение

- **Шапка:** как на prosebya.ru, обычная шапка уезжает вместе со страницей, после прокрутки примерно на 250px сверху выезжает компактная белая панель.
- **Масштаб:** брейкпоинт мобильной версии 960px. Шире 1440px вся страница растёт пропорционально ширине окна, как на Tilda (`zoom = ширина окна / 1440`, скрипт в `<head>`).
- **Карточки hero:** на десктопе «Как пользоваться» и «Что внутри» целиком кликабельны, на мобильной раскрываются по нажатию на заголовок.
- **Карусель:** стрелки листают на одну карточку, на мобильной карточки листаются свайпом.

## Допущения

- Картинки карточек и коллажей подключены с CDN сайта (`static.tildacdn.com`), локально они не хранятся.
- Ссылки карточек и кнопок ведут на страницы `yandex.prosebya.ru` (`/howto`, `/whatinside`), кнопка «Скачать приложение» на якорь `#download-apps`, как на сайте.
- Размеры десктопа сняты с живой страницы при ширине окна 1440px (у Tilda макет 1200px с масштабом ×1,2).
